# 개발 작업 체크리스트

기준 문서: `docs/work-plan.md` (v1.0). 작업을 끝낼 때마다 `[x]`로 표시한다.
표기: `[ ]` 미착수 / `[~]` 진행 중 / `[x]` 완료 / `[!]` 막힘(사유 기록) / `[-]` 이 환경에서 불가(사유 기록)

## 0. 개발 방침과 환경 제약

- 관리 프로그램 이름: **`ocx`** (OpenCode eXtended). 원본 `opencode`는 그대로 호출하고, `ocx`가 감싼다. `ocx`가 모르는 명령은 원본으로 그대로 넘긴다(passthrough).
- 구현: TypeScript + Bun, 위치 `manager/`. Bun `compile`로 단일 exe 생성(Windows x64 타깃).
- 이 작업 환경은 Linux이고 GPU·사내 LLM·Windows가 없다.
  - LLM이 필요한 테스트는 **모의 OpenAI 호환 서버**(지연·오류·느림 주입 가능)로 대체한다.
  - Windows 실행 테스트는 이 환경에서 불가 → 항목에 `[-]`로 표시하고 사용자 확인 과제로 남긴다.
- Git 자동 작업 금지는 **제품 동작**에 대한 규칙이다. 이 저장소의 커밋·푸시는 별도 권한 확인이 필요하며, 권한이 허용되기 전까지 변경은 로컬에 둔다.
- 코드의 주석은 한글로 쓴다.
