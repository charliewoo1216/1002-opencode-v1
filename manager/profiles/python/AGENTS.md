# Python 개발 지침

- 코드를 바꾸기 전에 기존 모듈 구조, 네이밍, 타입 힌트 사용 방식, 로깅 방식을 확인하고 그대로 따른다.
- 프로젝트가 쓰는 의존성 관리 방식(`requirements*.txt`, `pyproject.toml` 등)을 바꾸지 않는다. 새 의존성은 꼭 필요할 때만 추가하고 이유를 기록한다.
- 새 함수와 공개 인터페이스에는 타입 힌트를 붙인다 (기존 코드가 쓰는 수준에 맞춘다).
- 변경한 동작에는 pytest 테스트를 함께 추가하거나 수정한다.
- 비밀 정보와 환경별 설정은 코드에 직접 쓰지 않고 환경변수나 설정 파일로 받는다.
- 스택 버전과 최신 기법은 이 프로필의 `docs/` 폴더 문서에 정리된 내용을 우선한다. 문서에 없는 최신 기능은 확실하지 않으면 쓰지 말고 열린 질문으로 남긴다.
