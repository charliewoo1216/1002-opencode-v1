# AI/LLM 응용 개발 지침

- 이 환경은 폐쇄망이다. 외부 API 호출 코드를 넣지 않는다. 모델 접속은 설정으로 받는 사내 OpenAI 호환 HTTP 엔드포인트를 가정한다.
- 모델 이름, 주소, 키, 컨텍스트 길이는 코드에 고정하지 않고 설정으로 분리한다.
- 도구(function calling, MCP 도구)는 입력 스키마와 설명을 명확히 쓰고, 입력 검증과 오류 반환 형식을 정한다.
- MCP 서버를 만들 때: 서버 기동 방법, 도구 목록, 각 도구의 호출 예시와 테스트를 함께 작성한다. 테스트가 서버 프로세스를 띄웠다면 반드시 종료한다.
- 프롬프트는 코드와 분리된 파일이나 상수로 관리하고, 변경 시 기대 출력을 확인하는 테스트(또는 평가 스크립트)를 둔다.
- LLM 호출에는 타임아웃과 재시도 정책을 둔다. 응답 형식(JSON 등)은 파싱 실패를 처리한다.
- 스택 버전과 최신 기법은 이 프로필의 `docs/` 폴더 문서에 정리된 내용을 우선한다. 문서에 없는 최신 기능은 확실하지 않으면 쓰지 말고 열린 질문으로 남긴다.
